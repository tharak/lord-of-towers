# RawElement gathering implementation contracts

Historical implementation contract: tower capture references below are superseded by tower destruction in the current simulation. See the [entity catalog](entity-catalog.md).

Tests/builds run only on GitHub Actions. Local formatting allowed. Each agent owns its files and commits on its branch, no push/merge. Shared model.rs owned by lead; request changes if needed.

## Ownership and interfaces
- Simulation agent: src/simulation.rs only. Spawning, startup/reset, damage cargo drops, schedule, regression tests.
- Gathering agent: src/gathering.rs only. GatheringPlugin, deposits, local navigation, collection/delivery/trails, tests.
- Presentation agent: src/presentation.rs, src/inspector.rs, src/main.rs only.
- Lead: model.rs, lib.rs, energy/mod.rs (pickup systems removed), docs, browser tests, integration.

Shared model components already committed: RawElement(u32) on deposits/minions/towers, RawElementDeposit marker, Vision{radius}, GatheringState::{Exploring, Following{trip,sequence}, Returning{tower:Option<Entity>}}, Trail{trip,sequence,remaining}, TrailEmitter{trip,next_sequence,last_position}, RawElementEconomy{initial,spent}. EntityKind replaces EnergyPickup with RawElementDeposit and Trail. Spawner now only cap. SimulationConfig replaces spawn_interval with starting_minions=3/minion_raw_cost=5, energy_pickup_count with deposit_count=30, adds vision_radius=15, delivery_radius=3, trail_spacing=2, trail_lifetime=30. Obsolete recharge and energy seeking fields removed.

## Scheduling/start/reset
Simulation configures ordered gated fixed sets: Spawn (advance clock ONLY), Index, Target, Movement, Combat, Capture, Gathering, PaidSpawn, Energy, Influence, Victory. GatheringPlugin registers navigation in Target and chained decay/collection/delivery/trail emission in Gathering. Simulation registers paid spawning in PaidSpawn; EnergyPlugin now only network reconcile+transfer. Flush deferred effects via chains/ordered sets as appropriate.
Simulation create_match calls public gathering::spawn_deposits(commands, config), which creates seeded 30 deposits, resets gathering RNG/trip runtime, and inserts RawElementEconomy(initial=sum quantities, spent=0). Each initial deposit stable ID in high namespace >=1<<63. Export gathering::drop_cargo(commands, position, amount) to spawn a neutral deposit for death; stable ID from runtime is optional: stable fallback entity bits acceptable for drops. Drops are real MatchEntity deposits with Name, EntityKind, Position, RawElement; amount always1. No duplicate reset spawning. GatheringPlugin initialization should not overwrite create_match resources.
Simulation creates three initial minions per tower, zero tower stock. Use shared minion spawn helper for startup and paid spawning; initial minion IDs start5 and SpawnSequence after startup reflects all15. Every minion has EnergyStore(5/5), ForwardingCursor, RawElement(0), Vision, GatheringState::Exploring, and existing normal components. Nested bundles if tuple arity grows. Restart rebuilds initial armies and resets energy clock, RNG, economy, trails, links. Capture retains stock, resets forwarding cursor, creates no bonus minions.

## Navigation/resource loop
Gathering priority: cargo -> return; else visible deposit -> nearest friendly visible trail -> random exploration. Inclusive vision circle15; apply actual component radius. Friendly towers known globally solely for delivery. No global enemy/deposit/trail tracking. Visibility applies to target acquisition AND continued pursuit. No shared faction vision. Deposits priority over trails. Collection radius1, delivery3. Choose nearest friendly tower on collection; retain target until hostile/missing then nearest friendly, or wander holding cargo if none. Pick distance then stable ID ties. Navigation must not query resource quantity outside vision to change behavior.
Follow nearest visible friendly trail on join; same-trip decreasing sequence toward source, only visible candidates, strictly lower after reaching current marker; no source location stored in Trail. If continuation missing/expired, explore. Do not endlessly reacquire the same arrived terminal marker; remember exhausted trip until a new candidate/trip appears (can add private component in gathering.rs). Cargo state Returning; exploration target within10, retarget on arrival or3seconds, seeded RNG. Empty energy never changes gathering navigation.
Collection deterministic deposit order, collector distance/stable ID; each minion carries1; immediate inventory updates prevent double collection. Decrement deposit, despawn at0. Carriers deposit one to tower, clear cargo/emitter and resume exploration. Trail starts at collection (seq0), then every2 traveled units (last emitted position acceptable), sequence grows toward tower. Markers MatchEntity/Name/Kind/Allegiance/Position/Trail; expire after30 simulation seconds. Markers persist after creator death/delivery. Faction never changes on trail. Use scaled fixed dt; gated sets handle pause/hidden/victory. On death drop carried resource before minion despawn. Resource conservation: sum deposits/cargo/stock+spent=initial. Paid spawn spends5 each, no timed spawning; existing origin population cap100, no spending at cap, spawn all affordable under cap.
Combat still costs1energy, no chasing/stopping movement for enemies. Remove choose_targets and choose_energy_targets. collect_damage visibility bounds target selection by Vision; direct combat radius unchanged. Existing influence stays, no influence-based navigation. Cargo drops after combat, collection before paid spawn, graph after spawn.
