# Gathering contracts

Thirty seeded homogeneous deposits contain 5–10 units each, six deposits per element. `ElementInventory.units` is an ordered deque shared by deposit quantities, minion cargo, tower stock and order reservations. Deposits never recharge. Each new pickup first fills an empty equipment slot, skipping a slot reserved by a pending exchange. Only overflow becomes the single gathered cargo unit. Unequipped units also travel as cargo and can accompany that unit. Cargo is delivered within three units of a friendly tower. Death drops preserve types; empty deposits despawn.

Active held/released DragControl suspends gathering navigation, pickups and delivery until arrival/cancellation; existing cargo trails continue. Outside player control, navigation uses each minion's equipped-air/void-derived local vision. Only friendly tower delivery locations are globally known. Priorities are valid tower defense, pending tower-order travel or cargo return, closest visible enemy, visible deposit, freshest unvisited friendly trail, then random exploration. Carriers and ordered minions shoot in-range enemies without generic pursuit. Defense ends when the attacker leaves vision or the tower/attacker becomes invalid.

`GatheringState` is Exploring, Following { trip, sequence }, or Returning { tower }. Friendly trail selection ranks remaining lifetime, then distance and stable identity. Selecting a marker records all other visible live friendly markers in private per-minion `VisitedTrailMarkers`. The selected marker is visited on arrival within one unit. Despawned markers are pruned; no eligible markers resumes normal exploration. Sequence direction does not constrain following.

Only carriers create trails. At pickup and every two traveled world units, a carrier refreshes the nearest live friendly marker within `trail_spacing` (2), or creates one when none is nearby. Refresh resets lifetime to 30 simulation seconds without changing position, trip, sequence or visited memories. `TrailIds` allocates carrier trips. Decay uses simulation time, stops while paused, and scales with speed. Player drawing/erasing no longer exists.

NPC production consumes the oldest five stock units after nearby empty equipment slots are filled. Player production consumes a selected five-unit recipe. Both update consumed counts and newborn birth stats. Tower influence radius remains fixed at 15. See [equipment contracts](equipment-contracts.md) for reservations, transfers and conservation.


Deposit discovery, pickup eligibility and trail perception require a clear line of sight through the map’s building/tree footprints in addition to the existing vision and distance limits. Hidden trail markers are not marked visited by selection. Friendly delivery tower locations remain globally known. Trail emission/refresh and cargo delivery remain physical proximity rules.
