# Collaboration rules

Use Bevy ECS for gameplay and UI. Shared contracts live in src/components/, src/resources/, src/types/ and src/scheduling/; src/model.rs preserves legacy imports. Keep one custom component per file. Entity construction lives in src/entities/, behavior in src/systems/, and registration in src/plugins/. See docs/source-guide.md; coordinate shared contract changes with the lead agent. Keep simulation independent from mesh and material handles. Use only Bevy primitive meshes. Add all new application entity kinds and lifecycle rules to docs/entity-catalog.md.

Validation is compilation only: native cargo check and a release WebAssembly build in GitHub Actions. Do not add or run automated tests, browser suites, extended simulations, or runtime smoke checks. Investigate runtime issues when the user reports them. Local compilation is allowed when explicitly requested; formatting is allowed. Each agent owns its assigned files and must commit changes on its assigned branch. Never merge another agent's branch or alter shared interfaces without coordinating.

All Magna Urbis imports and calls must remain inside src/integrations/magna_urbis/. That adapter accepts application-owned settings and returns application-owned map data; upstream types must not leak into gameplay, UI, rendering, components, or resources. Preserve the pinned upstream snapshot and license under third_party/magna-urbis/.
